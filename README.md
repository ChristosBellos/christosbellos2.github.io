# The Sixth Man και στατιστικά ομάδων

Αυτό το repository είναι ενιαίο: το site [The Sixth Man](index.html) και η εφαρμογή στατιστικών EuroLeague / EuroCup. Το `main` είναι αυτό που φαίνεται στο [codebase](https://cursor.com/codebase/xristosmp2002/hoop-stats/tree/main).

Το site ανοίγει με `index.html`. Ο σύνδεσμος **European Team Stats** ανοίγει τη σελίδα `stats.html` στο ίδιο site. Δεν δείχνει σε `127.0.0.1`, γιατί αυτή η διεύθυνση υπάρχει μόνο στον υπολογιστή όπου τρέχει τοπικά το Streamlit.

# Στατιστικά ευρωπαϊκών ομάδων

Εφαρμογή σε Streamlit που διαβάζει μέσους όρους ομάδων από τη EuroLeague, το EuroCup, τη Liga ABA και τα εγχώρια πρωταθλήματα (Ισπανία, Ελλάδα, Τουρκία, Ισραήλ, Ιταλία, Γαλλία, Γερμανία, Λιθουανία). Τα αποθηκεύει σε SQLite και τα δείχνει με διαδραστικά γραφήματα.

Η ανανέωση αφορά τη σεζόν 2026-27. Όσο δεν έχουν παιχτεί αγώνες, η σελίδα γράφει «Μη διαθέσιμων στατιστικών». Όταν μια ομάδα εμφανίζεται σε περισσότερες διοργανώσεις, ο ενιαίος μέσος σταθμίζεται με τους αγώνες μόνο μέσα σε αυτή τη σεζόν. Η Ευρώπη (EuroLeague / EuroCup), η Liga ABA και το εθνικό πρωτάθλημα μένουν χωριστά.

Κάτω από την κάρτα υπάρχει επιλογή για τη σεζόν 2025-26, κομμένη στους ίδιους αγώνες που έχει δώσει φέτος η ομάδα σε κάθε διοργάνωση. Οι δύο σεζόν δεν μπαίνουν στον ίδιο μέσο όρο. Για EuroLeague και EuroCup το κόψιμο βγαίνει από το αρχείο αγώνων. Για τις υπόλοιπες διοργανώσεις, χωρίς αρχείο αγώνα-αγώνα, η αντίστοιχη αγωνιστική μένει μη διαθέσιμη αντί να εμφανιστεί ο μέσος όρος ολόκληρης της σεζόν.

## Εκτέλεση

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Τοπικά, η εφαρμογή Streamlit ανοίγει στο [http://127.0.0.1:47211](http://127.0.0.1:47211). Η βάση `data/basketball.db` περιλαμβάνει ήδη ένα στιγμιότυπο της σεζόν 2025-26. Το κουμπί **Ανανέωση Στατιστικών** ξαναδιαβάζει τους πίνακες, ενημερώνει τη βάση και ξαναγράφει το `stats-data.json`, ώστε και το Streamlit και η σελίδα `stats.html` να δείχνουν τα ίδια στατιστικά.

Από το τερματικό, η ίδια ανανέωση γίνεται με:

```bash
python scraper.py
```

## Τι κάνει κάθε module

- `scraper.py` κατεβάζει με `requests` τους πίνακες της RealGM και τη σελίδα στατιστικών της Euroleague. Επιστρέφει ένα pandas DataFrame με καθαρές στήλες (αγώνες, πόντοι, σουτ, ριμπάουντ, ασίστ).
- `database.py` αποθηκεύει και ενημερώνει τα στατιστικά, επιστρέφει τα ονόματα για την αναζήτηση και φέρνει το προφίλ μίας ομάδας.
- `app.py` είναι το UI: αναζήτηση, κάρτα μέσων όρων και γραφήματα Plotly.
- `names.py` ενώνει παραλλαγές ονόματος (χορηγοί, επίσημη ονομασία, ελληνικά ψευδώνυμα) στην ίδια ομάδα.

## Πηγές

Οι πίνακες της τρέχουσας σεζόν προέρχονται από τη RealGM (σεζόν 2027 στους συνδέσμους, δηλαδή 2026-27):

- Euroleague, Eurocup, Liga ABA
- ACB, Greek HEBA A1, Turkish BSL, Israeli BSL
- Lega Basket Serie A, Jeep Elite, German BBL, Lithuanian LKL

Η σελίδα παικτών της Euroleague (`euroleaguebasketball.net`, season `E2025`) ζητείται κι αυτή. Είναι εφαρμογή JavaScript και συχνά δεν επιστρέφει πίνακα σε απλό request. Όταν ο πίνακας της RealGM για τη Euroleague ή το Eurocup λείπει, χρησιμοποιείται το δημόσιο feed `api-live.euroleague.net` για τα traditional στατιστικά ομάδων της ίδιας σεζόν. Αν η RealGM απαντήσει, το feed δεν αποθηκεύεται δεύτερη φορά.

Η RealGM προστατεύεται από Cloudflare. Αν το απευθείας request δεν φέρει πίνακα, το module ξαναζητά την ίδια διεύθυνση μέσω αναγνώστη που επιστρέφει το περιεχόμενο της σελίδας σε κείμενο.
